# ChatOmniCoder

Консольное приложение для общения с ИИ, написанное на чистой Java с использованием «сырого» HTTP, подключающееся к локальной LLM через LM Studio.

## 📋 Обзор

ChatOmniCoder - это консольное приложение, которое позволяет общаться с локально запущенной AI-моделью через HTTP API LM Studio. Проект использует только стандартную библиотеку Java — в частности `java.net.HttpURLConnection` — без внешних фреймворков. Поддерживается сохранение контекста диалога.

## 🚀 Стек

### Backend
- **Java 21** - основной язык
- **java.net.HttpURLConnection** - «сырое» HTTP-взаимодействие (встроено в JDK)

### AI
- **LM Studio** - локальный LLM-сервер

## ✨ Возможности

- 💬 **Консольный чат**
  - Простой, минимумом зависимостей

- 🤖 **Связь с локальным ИИ**
  - Напрямую обращается к LM Studio по HTTP
  - Никаких облачных API, полностью работает офлайн

- 🧠 **Сохранение контекста**
  - ИИ помнит контекст.

- 🔧 **Минимум зависимостей**
  - Только стандартная библиотека Java
  - Никакого Spring, сторонних HTTP-клиентов и лишнего кода

## 🛠️ Быстрый старт

### Требования
- **Java 21+** (JDK)
- **LM Studio**
- Загруженная LLM-модель

### Установка и запуск

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/CkutlsGit/chatomnicoder
cd chatomnicoder
```

2. **Настройте LM Studio**
   - Откройте LM Studio и скачайте нужную модель
   - Перейдите во вкладку **Developer** (или **Local Server**)
   - Загрузите модель и нажмите **Start Server**
   - По умолчанию сервер запускается на: `http://localhost:1234/v1`

3. **Скомпилируйте проект**
```bash
javac -d out src/main/java/**/*.java
```

4. **Запустите приложение**
```bash
java -cp out Main
```

## 📦 Структура проекта
